## Задание №3: Слайдер изображений «Dark Interior»

Этот проект представляет собой современный, адаптивный слайдер для галереи изображений в стиле «тёмный интерьер». Он был разработан с использованием чистого HTML, CSS и JavaScript.

### Запуск проекта.

Проект полностью автономен и не требует установки дополнительных серверов или сборщиков.

1. Скачайте файлы репозитория или клонируйте проект к себе на компьютер.
2. Убедитесь, что папка с изображениями `img/` находится в той же директории (либо внутри кода прописаны актуальные пути к вашим фото).
3. Просто дважды кликните по файлу **`index.html`**, чтобы открыть сайт в любом современном браузере (Chrome, Яндекс.Браузер, Firefox, Safari).

**Клонирование репозитория** (если вы ещё этого не сделали):
1. Откройте терминал (командную строку) и выполните команду:
git clone https://github.com/DoZzer-Russ/practice-synergy.git
2. Перейдите в папку с проектом:
cd practice-synergy/task3
3. Откройте файл **`index.html`**
